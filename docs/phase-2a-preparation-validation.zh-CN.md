# M2-A 前置准备 P3–P6 准入报告

日期：2026-10-26。目标：忏悔原版 `1.7.9b.J835`、普通 Isaac、普通难度、全解锁槽 1。范围为进入 M2-A 开发所需的基础能力；不包含首层路线、Boss 集成和正常离层。

## 1. 结论与准入边界

**P0–P6 已具备进入 M2-A 开发的基础。** 构筑变化、健康资源账本、持续连接的房间执行、固定 EID 查询、有限拾取与被动经验链路已实现。完整本地回归 252 项通过。J835 开发场景已完成正常移动拾取属性道具、构筑修订、出门和实际战斗房清理，零失血，未调用 DeepSeek。

被动经验的测量→结论→进程重启检索→采用→反例失效已通过本地模拟闭环。本次实机仅获得 1 个有效弹速样本，未达 3 个样本的晋升门槛；没有生成该局经验，不宣称实机跨局复用已验证。无经验时使用普通泪弹先验，不能为产生结论自动启用主动实验。

P7 主动实验关闭且未实现；M2-A 不依赖它。P8 为组件、预算、版本及候选程序合同，完整运行器与 DeepSeek 编程归 M2-B。本次所有新增代码均为工程实现，不属于 DeepSeek 自动开发成果。

## 2. 代码与职责

| 模块 | 已实现职责 | 边界 |
|---|---|---|
| `combat/builds.py` | 合并实际库存/属性/临时效果，按语义变化发布 revision；失效旧攻击样本；缓存精确签名 | 不叠加 EID 数值；未知机制明确 UNSUPPORTED_BUILD |
| `combat/ledgers.py` | 损伤、骨心损失、授权生命支出、容器损失及资源消耗分开；空骨心存活和 120 更新复活窗口 | 生存依据 dead 标志；非净值可见的中间损失不能声称完全还原 |
| `combat/room_execution.py` | 房间状态/清房/异步规划生命周期；run/floor/visit 隔离；持续复用连接 | 不负责选下一扇门、整层图或 Boss 出口 |
| `knowledge_project/` | 独立安装的 EID 字面量导入器、固定 SQLite 包、只读 SDK | 不执行 Lua；不是完整协同求值器或 HTTP 服务 |
| `combat/item_knowledge.py` | 来源 Gateway、遭遇前态、拾取/拒绝/延后、能力缺口任务及 KnowledgeBundle | 拾取策略由宿主支持映射决定；描述不是可执行能力 |
| `combat/item_interaction.py` | 唯一输入通道下正常移动接近、预算/上下文检查、消费与入库确认、幂等结果 | 无主动道具/卡牌/药丸/炸弹操作；等待有界 |
| `combat/agent_store.py` | 独立经验 SQLite，保存决策、结果、测量、结论、反例和学习任务 | 不修改来源包；写入在边界通过线程执行，不放入逐帧求解 |
| `combat/item_learning.py` | 战中避让地上物品、清房后有限拾取、被动校准与按版本采用 | 每边界最多尝试 4 个拾取；不把经验值当新样本 |

连接入口为 `CombatSession.open/execute_room/close`；`run` 保留第一房兼容入口。`RoomExecutor` 每次切换取消旧异步计划、释放输入，清房不关闭服务。房间历史 128、计时样本 4,096、动作回执去重窗口 2,048，楼层已清房身份限 1,024；原始轨迹和数据库用于持久记录。

构筑/经验修订贯穿 ContextRef、计划、提案和执行校验。伤害收益统一为预测窗口累计量，普通泪弹默认 30 game_update。仅改变飞行/体型不清掉无关弹速样本；攻击相关签名变化不会使用旧的在途泪弹。校准签名包含目标构建和模型版本。

## 3. 来源和数据范围

固定 [EID 提交](https://github.com/wofsauge/External-Item-Descriptions/tree/8b59d00c6828e333294639ad2b2b6875eae821cb)：`8b59d00c6828e333294639ad2b2b6875eae821cb`。只导入 `ab+` 与 `rep` 的英文、中文四个文件，Repentance 静态说明覆盖基础说明，不混入 `rep+`/REPENTOGON 表。

- 数据集：`eid-16b584b65a6e506666e0cf71`；解析器 `eid-literals-1`；2,136 个语言记录，涵盖 collectible/trinket/card/pill_effect。
- 每条记录保留定位、源行、提交、正文来源哈希、原文标记、字面量解析状态。条件、动态修饰和协同覆盖明确不完整；SDK 不把未知返回成“无效果”。
- 包身份绑定源哈希、解析器、目标与使用策略；打开时核对 SQLite 哈希和语义身份。只读查询、分页游标绑定请求、语言回退与不兼容目标拒绝均有测试。
- 当前实现 `describe/lookup/lookup_interactions/get_evidence` 的最小子集；协同查询显式未知，证据查询仅元数据。未实现搜索、HTTP、异步来源任务和反馈接口。
- 来源策略 unknown 时，展示查询可本地查看文本，规划/开发查询不输出未授权正文；未审核说明不参与 BuildCompiler。策略是包身份的一部分。
- 知识来源包与智能体经验各有所有者。经验精确匹配校准签名，模拟来源不用于正常游戏校准；反例保留原结论的来源模式，不能跨模式污染晋升。

当前收藏品宿主支持表为 `1/4/12 → attributes`、`20 → flight`、`105 → inactive_active`。105 允许作为不使用的初始主动道具持有，不自动拾取替换它。未知饰品、临时效果、复杂武器、负 ID/动态机制和健康交易拒绝；免费普通钱/钥匙/炸弹拾取有资源增量确认。此表是窄范围实现映射，不是全道具价值排名。

## 5. 剩余范围

进入 M2-A 后仍需实现 FloorDirector、已探索地图与房间选择、Boss 适配、合法出口操作及独立 FloorJudge，并验证同一 run 的完整首层。当前成功仅证明窄范围道具变化下控制链路可持续，不保证任意房间、未知强制道具、复杂生命机制或稳定胜率。

后续被动采集达到门槛时补实机经验复用证据；新增机制需扩展支持映射、版本和针对性夹具。P7 启用前实现安全门与预算，M2-B 再实现模型机制程序、隔离验证和发布。未实施模型消融、大样本统计或重复付费回归。
