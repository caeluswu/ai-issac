## 适用边界

这是固定种子的工程可行性证据，不代表随机种子胜率、稳定通关 Mom 或竞速性能。第三层损失 5 个半心，显示长期资源与伤害控制仍是主要风险。运行中桥接打印过一次 JSON 解码错误，但其后继续接收状态并完成四层；该单次成功不能证明传输错误无影响。

此前保留的失败轨迹分别覆盖关闭 Host 无目标、旧站位排除耗尽、火堆上的拾取以及 Boss 出口生成时的保守几何重叠。当前代码对这些边界有针对性处理；只有本次同局成功覆盖了所遇到的组合，不将未遇到的全部变体写成已验证。
