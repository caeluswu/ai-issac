# J835 被动道具与 Boss 奖励支持

## 范围与实现

目标环境是忏悔原版 `1.7.9b.J835`、Isaac、普通难度、全解锁槽 1。Boss 奖励通过正常击败 Boss 后移动拾取；不使用控制台给予道具。固定种子 `3BYH A82R` 用于开发复现，不能代表随机种子胜率。

模组仅在主线第 1～6 层、普通维度、非失明诅咒且 Isaac 的底座身份可辨认时提供道具 ID；失明或身份条件不可核对时隐藏 ID。Python 先查询固定 EID 说明，再用 `item_capabilities.py` 判定普通泪弹输入是否仍适用。能力表按面板攻击属性、移动/飞行、生命与资源、独立跟班/附加输出划分。拾取后从游戏读取实际面板、生命、库存和武器类型；不按 EID 数值重复叠加。左/右眼非对称、随机属性和饰品生成明确保留修饰标记，攻击收益仍是近似值。

本机 `resources-dlc3/itempools.xml` 的 `boss` 池含 59 个唯一 ID，支持表覆盖 **59/59**；另有宝物房等来源的被动道具，总计登记 **155 个被动或跟班 ID**。`scripts/audit_item_support.py` 逐项核对固定 EID 英文记录完整性与本机 `items.xml` 的 passive/familiar 类型，审计结果没有缺失或误放行主动道具。覆盖表示能识别、拾取并保持普通控制链路；不是 155 个道具的逐项战斗验证或价值排序。特殊主武器、多发、激光、炸弹主动行为和饰品构筑仍需对应组件。

本地回归覆盖非失明的第二层可见性、失明和非普通维度的隐藏、Boss 属性奖励决策、构筑修订、跟班不重置玩家泪弹校准、随机/非对称标记与拾取后生命变化。实机只覆盖上述三个具体 ID 和一次固定种子两层运行。59/59 是静态准入覆盖，仍需在随机局中记录个别道具的效果、战斗收益和损失。商店付费购买、恶魔房生命交易、主动道具使用及完整 Mom 长局不由本次证据确认。
