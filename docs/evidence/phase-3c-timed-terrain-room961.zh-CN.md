# M3-C：无怪定时地形房的解谜控制

## 范围与分工

无怪房间不调用战斗攻击策略。`EnvironmentController` 从全房网格识别普通踏板、永久尖刺和周期尖刺；直接安全路径不存在、但经周期尖刺存在拓扑路径时，交给 `TimedTerrainPuzzle`。战斗求解器仍负责普通房间。当前实机覆盖忏悔原版 J835 的 Necropolis 房间类型 1、变体 961；未证明其他机关房通用。

该房的目标是触发索引 67 的踏板，确认房间清理，再经实际开启的门离开。所有移动与伤害计入同一运行账本；调试入口可用控制台 `stage 5a` 和 `goto d.961` 建立房间，这种初始化不计作正常长途通关证据。

## 控制链路

1. 读取全房网格，永久尖刺 `type=8` 始终不可通行；周期尖刺 `type=9` 仅在解谜器的时序搜索中作为候选通路。
2. 在安全地格靠近入口，记录每个周期尖刺的状态转换及共同周期。没有足够观测时等待，不猜测相位。
3. 在 `(地格, 周期相位)` 空间搜索整房路径；每条边按角色移动速度估时，并逐步检查碰撞半径覆盖的周期尖刺。可以在安全地格等待下一窗口，路线不局限于踏板的直线方向。
4. 按计划的出发时刻和路点执行短动作，逐帧用新位置重估；落后于计划时重搜。输入只含移动，不射击。解谜器一旦接管该房，负责到踏板触发，避免在周期尖刺上切换回普通寻路。
5. 踏板状态为 3、房间已清理且所有周期尖刺当前为 1 时，规划到所选门的室内地格，再交给门口过渡逻辑。若观测状态改变，则重新使用相位约束。

实机伤害回调的 `flags=128` 对应 [忏悔 API 的 `DAMAGE_SPIKES`](https://wofsauge.github.io/IsaacDocs/rep/enums/DamageFlag.html)。房间 961 中进入 `state=0` 的尖刺曾在转换后 46 帧造成伤害；该房以 `state=1` 作为候选安全相位，并留出转换保护帧。这是该房的实测语义，不应直接外推到其他机关类型。
