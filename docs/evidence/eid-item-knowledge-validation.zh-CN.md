# EID 单道具查询与知识库存储验证

日期：2026-10-27。实现基线：`2b6f3d1`。范围：固定 J835 EID 包的本地查询、按道具保存、跨进程复用和模型请求构造。验证不启动游戏、不发模型 HTTP 请求；不宣称全道具控制或动态说明完整覆盖。

## 实现与边界

原始 EID SQLite 保持只读。宿主配置独立声明项目内存储、规划和组件开发用途，保留来源 `rights.ai_input=unknown`，不修改来源 manifest 或 dataset_id。默认未传项目策略的 SDK 仍保持原来的正文过滤。

查询优先读取 `artifacts/knowledge/queried-items.sqlite`；首次找到说明后，先保存原始条目、源文件哈希、记录哈希和查询时间，再返回结果。同一 provider/dataset/kind/ID/请求语言只保留一条，中文回退英文时保留回退标记。刷新只重读固定本地包，来源版本更新另存不同键。未知 ID 不制造记录，单条损坏可回源修复，数据库不可写则明确报错。

规划、拾取与机制开发使用同一个 Gateway。EID 说明保留未审核标记，不能直接成为可执行机制，也不自动加入道具支持表。开发请求剔除缓存运行计数，保证同一内容在缓存命中前后保持一致；查询错误或正文缺失会在创建模型客户端之前停止。
