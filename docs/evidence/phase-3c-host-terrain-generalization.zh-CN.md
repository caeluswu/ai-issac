# M3-C：Host 连续交战与无怪地形通路

## 当前能力

J835 的 Host `27/0` 和 Red Host `27/1` 使用持续交战上下文。闭盖时选择可达攻击位置，开盖后保留路线，避免普通 Kite 评分把角色拉离射击走廊。武器组件决定射击、蓄力和释放；危险场继续评估全房敌人与弹体，攻击权限仍来自实际可攻击状态。

`EngagementRoute` 增加阶段与截止帧，分为接近、等待开盖和攻击。站位没有移动进展 60 更新或维持 120 更新没有收益时重新评估；失败站位冷却 180 更新，敌人位移至少 16 像素后重建记录。允许一轮真实攻击站位重试，不能靠每帧取消排除规则持续绕圈。未知开盖触发公式不作为已确认游戏机制。

解谜控制与战斗控制分开。普通踏板触发后不再作为下一目标；控制器重新选择未完成踏板，动态通路按全房地形规划。踏板产生敌人时交回战斗。已清房、没有踏板但存在周期尖刺的房间同样进入时序导航。

## 时序地形与监督

- 每个周期尖刺独立学习 30–300 更新内的周期，不要求整房周期相同。保留有限转换历史；超过 6 更新的观测空档使当前相位证据失效。
- 在 `(地格, 绝对帧)` 空间向前搜索最多 600 更新，允许中间安全区域等待；启发式使用静态移动距离，不计算多个周期的最小公倍数。
- 路径检查角色身体覆盖范围、实际移动属性和制动；速度、半径、地形与预测版本变化后重搜。飞行仅依据实际状态免除周期尖刺约束。
- 房间清理、踏板已按下都不会直接解除全部尖刺约束。对停止伸缩的尖刺，需要连续观察收回状态至少 306 更新，才采用静止通路估计；状态变化立即重新评估。这是有限观测支持的估计，不是对任意脚本机关的安全保证。
- 观测等待具有证据和截止帧；等待额度不能靠反复换 token 延长。单阶段最多 600 更新，无怪房和时序出门最多 1800 更新；普通出门维持原有期限。尖刺自行伸缩不计作任务进展。
- 同局以 run、楼层实例、房间索引和周期尖刺配置缓存已学习周期，最多 128 项。重新进入时获取当前相位，不复用离房前的时钟或安全结论。

当前范围是普通踏板、周期尖刺、静态障碍、门与安全等待区域。永久尖刺保持禁行；炸弹消耗、主动扣血、推物、未知脚本机关及战斗中的时序机关联合规划不在本轮实机支持声明内。

## 传输与调试入口

Lua 发送部分消息后按已发送索引续传，最多 8 次发送尝试，并使用 20 ms 重试准入期限。每次底层 socket 调用仍有原有 10 ms 超时，因此最后一次调用可能超过准入期限；失败立即断线并释放控制。测试覆盖部分发送、无进展与连接关闭，不能据此把所有命令超时归为同一个原因。

定向入口：

```powershell
.\.venv\Scripts\python.exe scripts/probe_host_route_j835.py --exact-fixture
.\.venv\Scripts\python.exe scripts/probe_host_route_j835.py --stage 4a --room 774
.\.venv\Scripts\python.exe scripts/probe_plate_j835.py --room 955 --exit
.\.venv\Scripts\python.exe scripts/probe_plate_j835.py --room 959 --exit
.\.venv\Scripts\python.exe scripts/probe_plate_j835.py --exit
```

精确 Host 场景通过独立初始化命令建立三个闭盖 Host 和原失败附近的玩家位置；不删除战斗中生成的弹体或修改生命来取得清房。已清地形房的探针选择远离出口、静态拓扑可达的安全起点，再由正常移动穿越。所有辅助初始化写入报告，不能算正常长途通关。

控制台 `goto` 使用地图外调试房，通常不能从出口房正常返回。`--reenter` 会明确记录缺少返回边的限制，不能把它写成重复进房验证；真实重入需要正常地图运行，另有快照回归覆盖新访问身份与相位重建。
